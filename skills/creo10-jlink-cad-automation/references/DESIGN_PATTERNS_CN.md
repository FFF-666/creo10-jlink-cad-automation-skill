# CAD 与两层微流道设计模式

## 1. 坐标与层高

- 先固定共同 XY 原点、设计包络、端口中心和单位；L1/L2 必须共享同一数据源或同一基准。
- 若 L1 从 `Z=0` 拉伸到 `t1`，L2 站在 L1 上方，则 L2 的基面为 `Z=t1`，顶面为 `Z=t1+t2`。
- 当前工程值：`t1=0.050 mm`、目标 `t2=0.035 mm`，组合顶面为 `Z=0.085 mm`。课程当前阶段是否强制这两个高度要与教师/工艺要求再次确认。
- L2 草图可以绘制在 L1 顶面或与其关联的偏置基准面上；不要把 L2 默认为从 `Z=0` 开始的重叠实体。

## 2. 居中主干与出口

- 主干可平行 X 轴并在 Y 方向居中；出口不必天然位于右下角，除非作业、夹具、外部管接头或版图标准明确固定。
- 当前设计要求保留右下出口时，使用“居中水平主干 → 斜线连接 → 右下端口”。真实中性版本使用水平段加 `-45°` 斜段。
- 连接处保持连续宽度、避免自交和过尖内角；用动态投影验证所有边都位于 L1 通道投影内。
- 当前固定端口中心记录为 `(4.5,3.5)`、`(4.5,12.5)`、`(22.5,3.5) mm`；若项目标准改变，先更新单一配置源再整体重生成。

## 3. L1 与 L2 的物理含义

- L1 是基底/主通道轮廓；当前“打印”L1 已按 `0.050 mm` 验收。
- L2 用于第二层导流、混合或障碍结构。若目的是让液体绕流并混合，叶片状结构通常在流道内表现为凸起的正实体/导流柱，而不是再挖一条普通凹槽。
- 工艺极性必须单独确认：在光刻胶母模上“凸起”，经 PDMS 等软光刻翻模后，最终流体空腔可能呈相反极性。当前对教师展示的胶状材料的工作推断是光刻/软光刻流程，不能仅凭外观替代课程工艺确认。
- L2 当前尚未完成内部细节，因此只能作为继续设计副本，不能标为最终制造模型。

## 4. 叶片/导流柱的画法

1. 在 L1 顶面建立 L2 草图基准。
2. 投影或引用 L1 边界和三个端口，只作定位参考。
3. 画一个闭合的叶片截面：可用短斜矩形、圆角楔形或类翼型轮廓。
4. 保证最小间隙、宽度和边界投影符合制造限制。
5. 只建立一个经过尺寸约束的基础特征。
6. 使用 Pattern/阵列或 Relations 生成重复结构；交替角度可形成人字/错列混合器。
7. 拉伸为正 L2 实体到 `0.035 mm`，再做完整再生与回读。

项目记录的 L2 特征宽度允许范围为 `0.02..1.0 mm`；已验证的居中主干示例采用 `0.080 mm`、6 条纹路、中心距 `0.10 mm`、中心线长度 `0.40 mm`、角度 `35°`。是否可制造还取决于设备分辨率、胶厚、曝光和脱模，不能只看 CAD 数值。

## 5. 可自由修改版本的优先结构

优先级：

```text
参数化 Creo 模板/原生 Sketch
→ 基础特征 + Pattern/Relations
→ sketch-only UDF + J-Link 变体尺寸
→ 配置驱动 DXF/STL/SVG 中性几何
→ GUI 手工或自动化（最后备用）
```

中性 DXF 可以自由修改曲线，但导入 Creo 后通常是导入特征，不等于拥有逐草绘尺寸可编辑的原生特征树。真正长期维护的版本应预先建立参数化模板或 UDF，然后由 Java 只改参数并单次再生。

## 6. 每次设计迭代的检查

- 单位为 mm，L1/L2 原点一致。
- 三个端口/孔位中心、直径和边界回读正确。
- 主干方向、斜向出口、连接连续性符合要求。
- 所有 L2 边和采样点投影在 L1 内。
- DXF 闭合、STL 无退化/非流形/重复面。
- Creo 完整再生、失败特征为 0、厚度和包围盒正确。
- 新版本写入时间戳或新修订，不覆盖前一版。
